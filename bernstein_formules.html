Polynômes de Bernstein

Formules essentielles & théorèmes fondamentaux
§ 01

Définition & Notation

Définition centrale
Polynôme de Bernstein de degré n, indice i
Bi,n(t) = C(n,i) · ti · (1−t)n−i
pour t ∈ [0,1]  ·  i = 0, 1, …, n  ·  n ∈ ℕ
Coefficient binomial
C(n,i) = n! / (i! · (n−i)!)
aussi noté (n choose i) ou ₙCᵢ
Cas particuliers
B0,n(t) = (1−t)n
Bn,n(t) = tn
B1,2(t) = 2t(1−t)
§ 02

Propriétés algébriques

Positivité
Bi,n(t) ≥ 0
∀ t ∈ [0,1]
Partition de l'unité
∑i=0..n Bi,n(t) = 1
Symétrie
Bi,n(t) = Bn−i,n(1−t)
Valeur en t=0
Bi,n(0) = δi,0
Valeur en t=1
Bi,n(1) = δi,n
Maximum
max atteint en t = i/n
δi,j désigne le symbole de Kronecker : 1 si i=j, 0 sinon.
§ 03

Relations de récurrence & Calcul

Récurrence (de Casteljau)
Bi,n(t) = (1−t)·Bi,n−1(t) + t·Bi−1,n−1(t)
avec Bi,0(t) = δi,0  ·  fondement de l'algo de de Casteljau
Élévation de degré
Bi,n(t) = ((n+1−i)/(n+1))·Bi,n+1(t)
               + (i+1)/(n+1)·Bi+1,n+1(t)
permet de passer du degré n au degré n+1 sans modifier la courbe
Produit de deux polynômes
Bi,m(t)·Bj,n(t) = C(m,i)·C(n,j)/C(m+n,i+j) · Bi+j, m+n(t)
Intégrale sur [0,1]
∫₀¹ Bi,n(t) dt = 1/(n+1)
tous les Bi,n ont la même intégrale sur [0,1]
§ 04

Dérivation

Dérivée première
B'i,n(t) = n · (Bi−1,n−1(t) − Bi,n−1(t))
avec convention B−1,n−1 = Bn,n−1 = 0
Dérivée k-ième
Bi,n(k)(t) = n!/(n−k)! · ∑j=0k (−1)k−j·C(k,j)·Bi+j, n−k(t)
Valeurs aux bornes
B'i,n(0) = n·(δi,1 − δi,0)
B'i,n(1) = n·(δi,n − δi,n−1)
§ 05

Théorèmes fondamentaux

Théorème · Approximation de Bernstein
Convergence uniforme (S. Bernstein, 1912)

Soit f ∈ C([0,1]). L'opérateur de Bernstein est défini par :

Bn[f](t) = ∑i=0n f(i/n) · Bi,n(t)

Alors :   ‖Bn[f] − f‖∞ → 0   quand n → +∞

La convergence est uniforme sur [0,1]. Ce résultat constitue une preuve constructive du théorème de Stone-Weierstrass.

Théorème · Vitesse de convergence
Estimée de l'erreur d'approximation

Pour f ∈ C([0,1]) de module de continuité ω(f, ·) :

‖Bn[f] − f‖∞ ≤ (5/4) · ω(f, 1/√n)

Si f est Lipschitz de constante L :

‖Bn[f] − f‖∞ ≤ L / (2√n)

Si f ∈ C²([0,1]) :

‖Bn[f] − f‖∞ ≤ ‖f''‖∞ / (8n)
Théorème · Base de polynômes
{B0,n, …, Bn,n} forme une base de ℙn

L'ensemble {Bi,n}i=0..n forme une base de l'espace vectoriel ℙn des polynômes de degré ≤ n sur ℝ.

Tout polynôme p ∈ ℙn s'écrit de façon unique :

p(t) = ∑i=0n ci · Bi,n(t)

Les coefficients ci sont appelés coefficients de Bézier ou points de contrôle.

Théorème · Variation diminuante
Propriété de variation diminuante (Schoenberg)

Soit p(t) = ∑ ci Bi,n(t) et L une droite quelconque. Alors :

#{intersections(courbe, L)} ≤ #{intersections(polygone de contrôle, L)}

La courbe ne peut osciller plus que son polygone de contrôle. Cela garantit la stabilité géométrique des courbes de Bézier.

Théorème · Préservation de la convexité
Convexité et monotonie

Si f est convexe sur [0,1], alors Bn[f] est aussi convexe et :

f ≤ Bn+1[f] ≤ Bn[f]

Si f est monotone croissante, Bn[f] l'est aussi. L'opérateur de Bernstein préserve la positivité, la monotonie et la convexité.

§ 06

Courbes de Bézier

Définition
C(t) = ∑i=0n Bi,n(t) · Pi  ,  t ∈ [0,1]
Pi ∈ ℝd sont les points de contrôle (d = 2 ou 3)
Points de passage
C(0) = P0
C(1) = Pn
La courbe passe exactement par les extrémités
Tangentes aux extrémités
C'(0) = n · (P1 − P0)
C'(1) = n · (Pn − Pn−1)
Algorithme de de Casteljau
Pi[0] = Pi
Pi[k](t) = (1−t)·Pi[k−1] + t·Pi+1[k−1]
C(t) = P0[n](t)
Stable numériquement — O(n²) opérations
Subdivision (de Casteljau)
Gauche : P0[0], P0[1], …, P0[n]
Droite : P0[n], P1[n−1], …, Pn[0]
Divise la courbe en t=τ en deux courbes de Bézier
§ 07

Changement de base & Conversions

Bernstein → Monomiale
Bi,n(t) = ∑j=in (−1)j−i·C(n,j)·C(j,i)·tj
Monomiale → Bernstein
tk = ∑i=kn C(i,k)/C(n,k) · Bi,n(t)
valable pour k ≤ n
Propriété · Stabilité numérique
La base de Bernstein est optimalement stable

Parmi toutes les bases de ℙn, la base de Bernstein minimise le conditionnement de la matrice de Gram sur [0,1]. Elle est préférable à la base monomiale pour les calculs numériques.
